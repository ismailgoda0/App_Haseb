# وثيقة نظام التصميم وتطابق واجهات Stitch — HomeCash Design System

## 1. نظرة عامة على نظام التصميم المعتمد (Stitch UI 2917847660260919585)
تم تصميم وتطوير واجهات تطبيق **HomeCash (دفتر المحافظ)** لتتطابق بنسبة 100% مع النموذج الأصلي على منصة Stitch ومجلد التصميم `I:\HomeCash\stitch_`.
يتميز التصميم بطابع فينتك (Fintech) عصري، موجّه للتجار والكاشير وأصحاب المحلات في مصر، مع دعم كامل للغة العربية (RTL) والأرقام اللحظية بالجنيه المصري (EGP).

## 4. تطابق الشاشات الأساسية مع مجلدات Stitch

### 1. الشاشة الرئيسية — Dashboard (`stitch_\_14`)
- **الهيدر:** صندوق أيقونة المتجر `40x40` باللون `#4F63E8`، اسم المتجر "محل الباشا فون"، بادج النبض الأخضر "متزامن مع SMS"، وزري البحث والتنبيهات مع بادج الفلاجات باللون الأحمر.
- **بطاقة الرصيد الكلي (`TotalBalanceCard`):** تدرج لوني بزاوية 135 درجة من `#4F63E8` إلى `#2A38A8`، زر إظهار/إخفاء الرصيد (العين)، بادج "محل / تاجر"، رقم رصيد بارز 36sp، ورقاقات حركة الوارد والصادر.
- **الإجراءات السريعة (`QuickActionsRow`):** 3 أعمدة متناسقة (تحويل سريع، معاملة يدوية، تقفيل وردية).
- **بطاقة تنبيه الفلاج (`FlagAlertCard`):** لون `#FFF7ED` بإطار `#FFD9A8`، أيقونة تحذير برتقالية `#FF7900`، وزر "معالجة الفجوة".
- **حركة السيولة والعمولات (`CashflowAnalyticsCard`):** خط بياني متعرج (Canvas Trend Line) للوارد والصادر، تفقيط صافي الأرباح، وبادج "مباشر".
- **المحافظ والخطوط (`WalletCard`):** بطاقات أفقية بعرض `290dp`، شعار الشبكة، بادج الشريحة (SIM 1)، حالة المحفظة "نشطة"، والرصيد اللحظي، مع صندوقين داخليين للوارد والصادر اليومي.

### 2. سجل المعاملات — Transactions (`stitch_\_15`)
- بطاقة كل معاملة بحواف دائرية `18dp`، صندوق اتجاه المعاملة `44x44` باللون الأخضر أو الأحمر، بادج الشبكة، رقم المستلم، المبلغ بالإنجليزية LTR، وبادج عمولة الكاشير المستحقة مع الرصيد بعد الحركة.
- فلاتر المحافظ بالأزرار البيضاوية (Chips) + شريط الاتجاه (الكل / وارد / صادر).
- نافذة تفاصيل المعاملة المطابقة لـ `stitch_\_18` مع نص رسالة الـ SMS الأصلية وكود المرجع.
- نافذة التحويل السريع مع اختيار نوع العملية، رقم الهاتف، والمبالغ الجاهزة (500، 1000، 2000، 5000 ج.م).

### 3. شاشة تسجيل الدخول والمصادقة — Auth (`stitch_\_8`)
- مطابقة 100% لشاشة `stitch_\_8`:
- زر تبديل اللغة (English / العربية) وزر تبديل الوضع الليلي والنهاري في الهيدر.
- شعار المحفظة بتدرج لوني بزاوية 45 درجة من `#4F63E8` إلى `#8795F8` مع إطار أبيض ناصع ووهج خفيف.
- حقول إدخال اسم المستخدم وكلمة المرور مع رابط "نسيت كلمة المرور؟" وأيقونة إظهار/إخفاء الرمز.
- زر الدخول الأساسي `#4F63E8` وزر تسجيل الدخول عبر Google.
- شريط أفقي للمحافظ المدعومة يحمل أيقونات وشعارات الشركات الرسمية.
- بطاقة الدعم الفني 24/7 مع زر تواصل مباشر.
- بطاقة طمأنة الخصوصية وتشفير الرسائل محلياً 100%.
- **معالج تهيئة الحساب الجديد (Onboarding Setup Wizard):** عند تسجيل الدخول بحساب `admin`، يظهر معالج من 3 خطوات تفاعلية لإعداد المتجر والمحافظ وتأكيد ربط 3 هواتف كاشير محاكاة وبدء التطبيق بحالة جديدة تماماً.

### 4. التقارير المالية والسيولة — Reports (`stitch_\_4`)
- شريط الفترات الزمنية المقسم (اليوم، الأسبوع، الشهر، مخصصة) مع منتقي الساعات القابل للطي.
- بطاقة Hero لربح عمولات الفترة مع نسبة النمو الإيجابي (`+18.5%`) ومؤشر العمليات الناجحة (284 عملية).
- بطاقتي الوارد والصادر مع أسهم التدفق المالي وحساب عدد الإيداعات والتحويلات.
- رسم بياني لمنحنى السيولة النقدية (Bezier Curve) بين الوارد والصادر خلال ساعات العمل.
- كشف توزيع الحركة على كل محفظة مع شعارات الشركات الرسمية وأشرطة التقدم الملونة.
- أزرار تصدير التقارير بصيغة Excel (XLSX) و PDF للوردية.

## 5. دليل شعارات ومزودي الخدمة (`app/src/main/assets/providers.json`)
يحتوي المشروع على ملف تكوين مركزي يشمل الهوية البصرية الرسمية لجميع مزودي خدمات الدفع والمحافظ في مصر:
1. فودافون كاش (`vodafone_cash`)
2. إنستاباي مصر (`instapay`)
3. اتصالات كاش (`etisalat_cash`)
4. أورنج كاش (`orange_cash`)
5. وي باي (`we_pay`)
6. فوري باي (`fawry`)
7. محفظة CIB الذكية (`cib_smart_wallet`)
8. محفظة بنك مصر (`bm_wallet`)
9. فون كاش البنك الأهلي (`nbe_phonecash`)

يتم عرض الشعارات في التطبيق عبر مكوّن Jetpack Compose المخصص `ProviderLogo(providerId, size)` في كافة البطاقات والفلاتر وشاشات السجل.

## 6. مشغل التشغيل المساعد (`run_homecash.bat`)

النسخة الموزعة من السكربت أصبحت عامة: تستخدم `ANDROID_SDK_ROOT` أو `ANDROID_HOME`، تبني APK، تعرض الأجهزة المتصلة، وتطلب اختيار الجهاز صراحةً. لا تمسح بيانات التطبيق ولا تحتوي على معرف هاتف أو مسار SDK خاص بجهاز مطور.
ملف أوامر تنفيذي تفاعلي يقدم للمستخدم:
- **[1] تشغيل التطبيق التجريبي على الهاتف الحقيقي اللاسلكي** عبر ADB مع تصفير الذاكرة المؤقتة للبدء من جديد.
- **[2] تشغيل على شاشة افتراضية في الويندوز** عبر محاكي Android Emulator (`Pixel_34`).
- **[3] مسح بيانات التطبيق والتخزين المؤقت فقط** (Clean Data & Cache).
- **[4] إعادة بناء وتجميع حزمة APK**.

### 5. الإعدادات وإدارة الأجهزة — Settings (`stitch_\_17`)
- بادج حالة الوضع التجريبي ومحاكاة الـ 3 هواتف مع زر التبديل الفوري.
- بطاقة المتجر والمشرف.
- قسم مزامنة الأجهزة الكاشير المتصلة (3 أجهزة بالبطارية وحالة الاتصال).
- إعدادات رمز الأمان والـ PIN لحماية الحساب.
- خيار تسجيل الخروج الآمن.

### 6. شريط التنقل السفلي — Bottom Navigation Bar
- ارتفاع `72dp`، زوايا علوية مستديرة `22dp`.
- وسادة بيضاوية `#EEF1FF` للتبويب النشط مع الأيقونة واللون `#4F63E8`.
