# 05 — المزامنة السحابية وتعدد الأجهزة (Multi-Device & Cloud Sync)

يوفر **HomeCash** دعماً كاملاً وغير محدود لربط عدة هواتف وشرائح SIM على حساب واحد، مما يتيح لصاحب المحل أو مدير النشاط مراقبة كافة الكاشيرات والفروع في شاشة موحدة حية.

---

## 1. نموذج تعدد الأجهزة (Multi-Device Topology)

```
                       [قاعدة البيانات السحابية المجانية عبر الإنترنت]
                     (Firebase Realtime DB / Supabase REST API)
                                         ▲
                     ┌───────────────────┼───────────────────┐
                     │                   │                   │
                     ▼                   ▼                   ▼
            [هاتف كاشير الفرع 1]   [هاتف كاشير الفرع 2]   [هاتف الإدارة - المالك]
            (شريحة فودافون + اتصالات) (شريحة أورنج + وي)    (متابعة فورية + تقارير)
```

1. **هاتف الكاشير 1 (Phone 1):** يستقبل رسائل تحويلات فودافون كاش واتصالات كاش الخاصة بالفرع الأول.
2. **هاتف الكاشير 2 (Phone 2):** يستقبل رسائل أورنج كاش وإنستاباي للفرع الثاني.
3. **هاتف المالك / الإدارة (Phone 3):** يعرض إجمالي السيولة المجمعة لكافة الفروع، أرباح اليوم، وفلاجات الفروق المالية لحظياً.

---

## 2. بروتوكول المزامنة السحابية (`CloudSyncApi`)

يعتمد النظام على بروتوكول REST خفيف وسريع متوافق مع قواعد البيانات السحابية المجانية:
- **نقطة النهاية الافتراضية:** يمكن ربطها بقاعدة بيانات مجانية عبر:
  `https://<project-id>.firebaseio.com/users/<user_id>/...` أو `Supabase PostgREST`.
- **المعالجة غير المتزامنة:** تتم عمليات الرفع في خيط خلفي منفصل (`Dispatchers.IO`) عبر مكتبة `OkHttp` دون تعطيل واجهة المستخدم نهائياً.

### الحزم المتبادلة سحابياً:
1. **مزامنة المعاملات (`syncTransaction`):**
   - رفع بيانات العملية فور تسجيلها محلياً متضمنة معرف الجهاز المنفذ (`deviceId`)، المبلغ، العمولة، والرصيد المتبقي.
2. **نبض الأجهزة والاتصال (`syncDeviceHeartbeat`):**
   - إرسال نبضة حية كل فترة لتحديث حالة الهاتف (`ONLINE` / `OFFLINE`) ووقت آخر نشاط.
3. **مزامنة أرصدة المحافظ (`syncWalletBalance`):**
   - تحديث الرصيد الحي للمحفظة فور حدوث أي حركة مالية.

---

## 3. العمل في حالة انقطاع الإنترنت (Offline-First Guarantee)

- يظل التطبيق يعمل محلياً بنسبة 100% بكامل كفاءته في تسجيل الرسائل وحساب العمولات حتى إذا انقطع الاتصال بالإنترنت تماماً في المحل.
- يتم تخزين العمليات محلياً في جدول `transactions` مع وسم `isSynced = false`.
- فور عودة الاتصال، يقوم `CloudSyncWorker` أو واجهة التطبيق برفع كافة الحركات المعلقة تلقائياً دون أي تكرار عبر فحص بصمة العملية (`fingerprint`).
