# 01 — نظرة عامة على المشروع (Project Overview)

> **اسم المشروع:** دفتر المحافظ — HomeCash  
> **المنصة:** Android Native (Jetpack Compose + Kotlin + Room + WorkManager)  
> **اللغة والاتجاه:** العربية بالكامل (RTL) مع دعم الأرقام الإنجليزية والمشرقية  
> **العملة المعتمدة:** الجنيه المصري (ج.م. / EGP)  
> **الهدف الأساسي:** أتمتة إدارة وتدقيق المعاملات المالية الواردة والصادرة عبر المحافظ الإلكترونية المصرية والحسابات البنكية (فودافون كاش، إنستاباي، اتصالات كاش، أورنج كاش، وي باي، البنك الأهلي، CIB، وبنك مصر)، وتحويل رسائل الـ SMS والإشعارات إلى دفتر حسابات آلي فوري.

---

## 1. المشكلة التي يحلها التطبيق

في السوق المصري، يعتمد مئات الآلاف من الأفراد وأصحاب المحلات والتجار (محلات الموبايل، الأكشاك، مراكز الصيانة، مقدمي خدمات الدفع الإلكتروني) على المحافظ المالية. ولكن يواجه هؤلاء تحديات يومية جسيمة:
1. **ضياع وتراكم رسائل الـ SMS:** مسح الرسائل أو تراكمها يؤدي لضياع أثر المعاملات والسيولة.
2. **فروق الأرصدة (Discrepancies):** حدوث عمليات لم تصل رسائلها، أو رسائل وصلت متأخرة، مما يسبب عجزاً أو زيادة غير مبررة في الدرج.
3. **تعدد الخطوط والأجهزة:** يمتلك التاجر عدة هواتف وشرائح SIM (شريحة فودافون، شريحة اتصالات، شريحة أورنج)، ويصعب مراقبة ما يحدث على كل هاتف بدون شاشة موحدة.
4. **حساب العمولات وصافي الأرباح:** يحتاج الكاشير لحساب عمولة الإرسال والاستقبال تلقائياً دون الحاجة لحسابات يدوية معقدة في نهاية الوردية.
5. **النصب والرسائل المزيفة:** محاولات احتيال يقوم فيها البعض بإرسال رسائل نصية من أرقام عادية تشبه رسائل الشركات لإيهام التاجر بوصول المبلغ.

---

## 2. الهيكل العام للتطبيق والوضعان الرئيسيان

يوفر HomeCash نمطين تشغيليين مع الحفاظ على نفس البنية والتصميم:

| البعد | الوضع الشخصي (Personal Mode) | الوضع التجاري / الكاشير (Business Mode) |
| :--- | :--- | :--- |
| **المستخدم المستهدف** | الأفراد وأصحاب الميزانيات الشخصية | المحلات، الكاشيرات، التجار، والشركات |
| **الرصيد الكلي** | مجموع أرصدة محافظك الشخصية | إجمالي السيولة عبر كافة محافظ وأجهزة الفروع |
| **الإحصائيات الرئيسية** | مصروف اليوم + شريط استهلاك الميزانية الشهرية | ربح اليوم (صافي العمولات) + إجمالي حجم التداول |
| **تقفيل الوردية** | غير متاح | متاح بنقرة واحدة لحساب عجز وزيادة الدرج النقدي |
| **كشف حساب الطرف الآخر** | اختياري | أساسي لعرض سجل العميل أو المورد وأرباحه |
| **تعدد الأجهزة والخطوط** | متاح بلا حدود | متاح بلا حدود مع ربط أجهزة الكاشيرات بالمالك |

## 3. الشاشات الرئيسية

1. **شاشة الدخول (Login):**
   - دخول باسم مستخدم وكلمة مرور.
   - زر سريع للدخول بحساب المدير التجريبي (`admin` / `admin`).
   - رسالة طمأنة الخصوصية والأمان.

2. **الشاشة الرئيسية (Dashboard):**
   - بطاقة الرصيد الإجمالي المجمعة مع إمكانية إخفاء/إظهار الرصيد.
   - شرائح المحافظ الأفقية التفاعلية مع مؤشرات ألوان كل شركة.
   - بطاقات إحصائية حية لصافي الأرباح وحجم التداول.
   - بطاقة التنبيهات الذكية للفلاجات وفروق الأرصدة.
   - شريط المحاكاة الذكي لتجربة 3 هواتف دون تكلفة.
   - قائمة أحدث المعاملات مع نافذة التفاصيل وكشف حساب الطرف الآخر.

3. **سجل المعاملات (Transactions):**
   - محرك بحث بالاسم، الرقم، المبلغ، أو كود العملية.
   - فلاتر الاتجاه (وارد، صادر) وفلاتر المحافظ المحددة.
   - زر إضافة معاملة يدوية نقدية (`+ معاملة يدوية`).

4. **التقارير المالية (Reports):**
   - محدد الفترات: اليوم، الأسبوع، الشهر، أو كافة الفترات.
   - ملخص مالي: إجمالي الوارد، الصادر، صافي الحركة، وصافي العمولات.
   - جدول أداء المحافظ والسيولة.
   - تصدير تقارير Excel و PDF.

5. **تقفيل الوردية (Shift Closing):**
   - حساب النقدية المتوقعة بالدرج آلياً.
   - إدخال النقدية الفعلية المحصية وحساب العجز أو الزيادة.

6. **كاشف الفجوات وحل الفلاجات (Flag Resolution):**
   - تشخيص فوري لأسباب فرق الرصيد أو تكرار العمليات.
   - زر الحل الجماعي (Batch Resolution) لاعتماد الأرصدة بنقرة واحدة.

7. **الإعدادات (Settings):**
   - التبديل بين الوضع الشخصي والتجاري.
   - إدارة أجهزة المحل المتصلة (3 هواتف) ومتابعة وقت آخر مزامنة.
   - التحكم في محاكي الرسائل الوهمية.
   - قفل التطبيق برمز PIN.
