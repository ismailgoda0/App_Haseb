# حاسب | Haseb — Android Studio

مشروع Android Native باستخدام Kotlin وJetpack Compose وRoom، مع الاحتفاظ بمصادر تصميم Stitch الأصلية داخل `design-reference/stitch/` وتضمين صفحات HTML داخل `app/src/main/assets/stitch/` لاستخدامها محليًا في تدفق الإعداد الأولي.

## ما تغيّر في هذه النسخة

- اسم التطبيق الظاهر: **حاسب**، والاسم الإنجليزي **Haseb**، مع أيقونة تطبيق مخصصة.
- خطوات الإعداد الأولي تستخدم صفحات Stitch الأصلية المحددة: `1_3` ثم `2_3` ثم `3_3_2` بدل شاشات Compose البديلة.
- أضيف مركز إشعارات داخل التطبيق مع سجل محفوظ محليًا، وقناة Android للإشعارات النظامية، وطلب صلاحية الإشعارات، وتنبيهات للمعاملات اليدوية ومعاملات SMS والفروقات ومراجعة التكرار وإقفال الوردية.
- زر الجرس في الرئيسية يفتح مركز الإشعارات، ويظهر عدّاد للتنبيهات غير المقروءة.
- تم الإبقاء على الشاشات الأصلية الأخرى في Compose حيث ترتبط حاليًا بالبيانات والعمليات، مع ملفات Stitch المرجعية كاملة داخل المشروع. **ليست كل صفحة Stitch مستقلة منقولة بعد إلى شاشة Android مطابقة حرفيًا**؛ راجع تقرير المراجعة قبل اعتبار التطبيق جاهزًا للإنتاج.
- لا يتم تضمين Google OAuth Client Secret في التطبيق. مسار Google يمر عبر Supabase OAuth/PKCE.

## فتح المشروع

1. فك الضغط وافتح المجلد `homecash_review` في Android Studio.
2. استخدم JDK المتوافق مع Gradle وAndroid Gradle Plugin، وثبّت Android SDK 36.
3. افتح `gradle.properties` واضبط `HOME_CASH_SUPABASE_URL` على رابط مشروعك الحقيقي من Supabase: `https://<project-ref>.supabase.co`.
4. مفتاح Supabase العام `sb_publishable_...` مضبوط في ملف المشروع. لا تضع `service_role` أو كلمة مرور PostgreSQL أو Google Client Secret في التطبيق.
5. راجع `ANDROID_STUDIO_SETUP.md` و`supabase/schema.sql`، ثم نفّذ Gradle Sync و`Build > Make Project`.

## تنبيه بخصوص الاتصال

لم يُذكر رابط مشروع Supabase في المعلومات المقدمة، لذلك لا يمكن إكمال اختبار المصادقة أو تأكيد اتصال المشروع الفعلي قبل إدخال الرابط. كما لم يكتمل بناء APK في بيئة العمل لأن تنزيل Gradle من `services.gradle.org` تعذّر بسبب عدم توفر اتصال DNS.

## التجربة

يمكن استخدام حساب العرض المحلي `admin / admin` لاختبار الواجهة فقط. هذا ليس حساب إنتاج ولا ينبغي استخدامه مع بيانات مالية حقيقية. اختبر Google OAuth وصلاحيات SMS والإشعارات وسياسات RLS على هاتف حقيقي قبل الاعتماد على التطبيق.
